# Passkey Login Prototype

Self-contained click-through prototype for pay.com.au passkey login.

Once this repo is deployed via GitHub Pages, the live demo will be at:
`https://<your-username>.github.io/<repo-name>/`

## How to deploy

1. Create a new public repo on GitHub.
2. Drag the contents of this folder (`index.html` and this README) into the repo via **Add file → Upload files**.
3. Commit.
4. Go to **Settings → Pages** → set **Branch: `main`**, **Folder: `/ (root)`** → **Save**.
5. Wait ~30–60s. Refresh the Pages settings — your live URL appears at the top.

That URL is shareable with anyone.
